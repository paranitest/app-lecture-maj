# Lectures — mises à jour

Les fichiers que les applications viennent chercher toutes seules
(Réglages → Application). Le code est ailleurs.

## Installer la première fois

- **Android** : télécharger `lectures.apk`, l'ouvrir, autoriser l'installation.
- **Windows** : télécharger `Parani27.exe` et le double-cliquer. Il va chercher
  le moteur (`moteur.zip`, 44 Mo) au premier lancement, puis se met à jour
  tout seul depuis l'application.

Pour télécharger un fichier : cliquer dessus, puis le bouton « Download raw
file » (l'icône de téléchargement en haut à droite).

`version.json` dit la version du jour, une clé par plateforme.
